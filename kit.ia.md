# 🤖 Kit IA — Plan d'utilisation des chatbots

> Module ICT 291 — Réaliser une application web · Auteur : Dany Henzer

## 1. Objectif

Utiliser l'IA comme **assistant d'apprentissage**, pas comme remplaçant. L'IA m'aide à comprendre, à trouver des idées et à corriger mes erreurs, mais **c'est moi qui écris, teste et valide** le code de mon projet *DHgraphics*.

## 2. Outils utilisés

| Outil | Usage principal | Quand |
|-------|-----------------|-------|
| **ChatGPT / Claude** | Explications, idées, relecture de texte | Recherche, théorie, Markdown |
| **GitHub Copilot** (VS Code) | Autocomplétion, petites suggestions de code | Pendant le code |
| **Copilot Chat** (VS Code) | Expliquer une erreur, un bout de code | Débogage |

## 3. Quand j'utilise l'IA ✅

- Comprendre une notion (Git, Markdown, HTML/CSS, JS…)
- Expliquer un message d'erreur
- Proposer plusieurs idées de design ou de structure
- Relire et corriger l'orthographe d'un README
- Générer des **données fictives** pour tester l'app

## 4. Quand je ne l'utilise pas ❌

- Copier-coller un exercice entier sans le comprendre
- Pendant les évaluations (sauf autorisation)
- Pour des données personnelles ou confidentielles (mots de passe, clés API, infos d'autres élèves)

## 5. Méthode de prompt

1. **Contexte** : « Je suis apprenant en ICT 291, je fais un site vitrine… »
2. **Tâche** : ce que je veux précisément
3. **Contraintes** : langage, niveau, longueur
4. **Format** : liste, tableau, code commenté…

**Exemple :**
> « Je suis débutant en HTML/CSS. Explique-moi comment centrer un logo à gauche et un bouton à droite dans un header, avec un exemple court et commenté. »

## 6. Vérification

- [ ] Je relis et **comprends** chaque ligne proposée
- [ ] Je **teste** le code dans le navigateur
- [ ] Je compare avec la documentation officielle (MDN, docs GitHub)
- [ ] Je **cite** l'IA quand une partie importante vient d'elle
